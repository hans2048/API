# GLB Viewer

브라우저에서 바로 실행되는 **GLB/GLTF 3D 파일 뷰어**입니다.  
서버 설치 없이 `glb-viewer.html` 파일을 브라우저에서 열기만 하면 사용할 수 있습니다.

---

## 사용법

### 파일 열기

| 방법 | 설명 |
|------|------|
| 드래그앤드롭 | GLB/GLTF 파일을 뷰어 화면에 드래그앤드롭 |
| 파일 선택 | `+ 파일 추가` 버튼 클릭 후 파일 선택 |
| 복수 파일 | 여러 파일을 동시에 드롭하면 **하나의 씬에 통합**되어 표시 |
| 추가 로드 | 모델이 이미 표시된 상태에서 추가 파일을 드롭하면 씬에 병합 |

### 뷰 컨트롤

| 조작 | 동작 |
|------|------|
| 마우스 좌클릭 드래그 | 모델 **회전** |
| 마우스 우클릭 드래그 | 카메라 **패닝** (이동) |
| 마우스 휠 | **줌 인/아웃** (확대/축소) |
| ⊡ 버튼 | **줌 핏** — 모든 모델이 화면에 꽉 차도록 카메라 자동 조정 |
| ⟳ 버튼 | 카메라 **초기 위치로 리셋** |
| ⬡ 버튼 | **와이어프레임 모드** 토글 |

### 모델 관리 (좌측 사이드바)

| 기능 | 설명 |
|------|------|
| 색상 표시자 | 각 모델을 구분하는 고유 색상 |
| 토글 스위치 | 개별 모델 표시/숨김 |
| ✕ 버튼 | 해당 모델을 씬에서 제거 |
| 전체 삭제 | 씬의 모든 모델 제거 |

## 프로그램 구조

```
glb-viewer.html  (단일 파일 — 외부 의존성 없음)
│
├── HTML/CSS  — 레이아웃 및 UI 스타일
│   ├── header          : 제목 및 설명
│   ├── #sidebar        : 모델 목록 패널 (토글·삭제·전체삭제)
│   └── #main           : 3D 뷰포트 + 컨트롤 버튼
│
└── JavaScript (ES Module, Three.js CDN)
    ├── Renderer        : WebGLRenderer (안티앨리어싱, 그림자 활성화)
    ├── Scene           : 조명(Ambient + Directional × 2) + 그리드
    ├── Camera          : PerspectiveCamera (FOV 45°)
    ├── OrbitControls   : 회전 / 줌 / 패닝 + 댐핑
    ├── GLTFLoader      : GLB/GLTF 파싱 및 씬 추가
    ├── loadFiles()     : 복수 파일 병렬 로드, 진행 상황 표시
    ├── addModel()      : 씬에 모델 추가, 사이드바 항목 생성
    ├── fitAll()        : 전체 모델 BoundingBox 계산 → 카메라 자동 배치
    └── toggleWireframe(): 전체 메쉬 와이어프레임 토글
```

### 핵심 로직 — 다중 파일 통합 표시

1. 드롭된 파일을 `URL.createObjectURL()`로 임시 URL 생성
2. `GLTFLoader`로 병렬 로드 (각 파일 독립적으로 비동기 처리)
3. 모든 모델을 **동일한 Three.js Scene에 추가** → 한 화면에 통합
4. 로드 완료 후 `fitAll()` 자동 호출 → 전체 모델이 화면에 맞게 카메라 조정
5. 각 모델의 `Group`을 개별 관리하여 독립적 표시/숨김·삭제 가능

---

## 기술 스택

- **Three.js** r165 (CDN) — 3D 렌더링
- **GLTFLoader** — GLB/GLTF 파일 파싱
- **OrbitControls** — 마우스 기반 카메라 제어
- 순수 HTML/CSS/JS — 빌드 도구 불필요

## 지원 파일 형식

- `.glb` — Binary GLTF (권장)
- `.gltf` — Text GLTF (외부 리소스가 없는 경우)
